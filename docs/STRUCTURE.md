# Estructura sugerida

- `docs/`: documentación funcional y técnica.
- `src/`: fuentes del sitio (HTML/CSS/JS).
- `data/`: archivos de datos como `org.yaml`.
- `scripts/`: utilidades de desarrollo y despliegue local.
- `backup/`: respaldos manuales temporales.

Estado actual aplicado:

- `src/index.html` y `src/styles.css`
- `data/org.yaml`
- `scripts/serve.sh`
- `backup/index-backup.html` y `backup/index-copy.html`
